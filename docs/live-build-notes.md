# XaiBoot live-build Notes

## Foundation

XaiBoot uses Debian live-build as the source of truth for image generation.
The `auto/config` script records the `lb config` options so a rebuild does not
depend on undocumented shell commands.

## Live User

The boot arguments in `auto/config` pass:

```text
username=xaiboot hostname=xaiboot
```

Those arguments are consumed by Debian's live-config components during live
boot. The user is not created manually in a hook because live-config already
owns the live-user lifecycle.

## Autologin

Autologin is intentionally limited to `tty1` by a systemd getty drop-in:

```text
/etc/systemd/system/getty@tty1.service.d/override.conf
```

This is simpler than adding a display manager and keeps rescue boot behavior
predictable.

## Desktop

XFCE, Xorg, and xinit are installed. A display manager is not installed by this
project. `/etc/X11/xinit/xinitrc` starts XFCE, so the live user can run either:

```bash
xaidesktop
startx
```

The default target is set to `multi-user.target` by
`config/hooks/normal/010-xaiboot-default-target.hook.chroot`.

## Boot Menu Branding

The root `isolinux-bg.png` artwork is included in the binary ISO filesystem at
both bootloader splash paths:

```text
config/includes.binary/isolinux/splash.png
config/includes.binary/boot/grub/splash.png
```

The ISOLINUX menu generated by live-build references `splash.png` from the
`isolinux/` directory. The GRUB path covers the UEFI boot menu tree generated
by live-build.

## Package Lists

Package lists are split by purpose:

- `xaiboot-rescue.list.chroot` for shell, hardware, storage, and recovery tools
- `xaiboot-network.list.chroot` for network and remote-access tools
- `xaiboot-desktop.list.chroot` for XFCE and GUI helpers

Each file is consumed directly by live-build because it ends with
`.list.chroot` and lives under `config/package-lists/`.
